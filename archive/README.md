# Archive

Earlier iterations, kept unmodified (apart from one local Windows path removed from the `.spec`).

- `IoTproject.py` (Feb 2024): first prototype, built from the Hackster finger-counting tutorial.
- `FinalCode.py` / `FinalCode.spec` (Mar 2024): the competition build. Adds a Tkinter window and
  voice commands (`speech_recognition`) next to the gestures, uses `COM9`, and was packaged
  with PyInstaller into a single Windows executable.
- `Python Code.ipynb`: notebook experiments with the gesture script.
- `Arduino_Code/Arduino_Code.ino`: the older Arduino sketch (relays default to whatever the pins power up as).

The maintained versions are in `../src` and `../arduino`.
